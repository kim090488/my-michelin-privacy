개인정보처리방침

시행일: 2026년 10월 5일

나만의 맛집(이하 "서비스")은 이용자의 개인정보를 소중히 다루며, 관련 법령을 준수합니다. 본 방침은 서비스가 수집하는 정보의 종류, 이용 목적, 보관 기간, 제3자 제공, 이용자의 권리를 설명합니다.

1. 수집하는 개인정보

서비스는 다음 정보를 수집합니다.

  • 계정 정보: Google 또는 Kakao OAuth 로그인 시 제공되는 이메일, 이름(닉네임), 프로필 이미지. 사용자가 별도 설정하는 사용자명·자기소개·아바타.
  • 위치 정보: 맛집 등록 또는 방문 기록 시점의 GPS 좌표. 가게 좌표와 약 200m 이내인지를 검증하는 데 사용되며, 검증을 위해 해당 리뷰·방문 기록과 함께 저장됩니다. 위치 정보를 지속적으로 추적하거나 다른 목적(광고·분석 등)으로 사용하지 않습니다. 본인 외에는 공개되지 않습니다.
  • 알림 토큰 및 디바이스 정보: 모바일은 Expo Push Token, 웹은 Web Push 구독 정보(endpoint, p256dh, auth)와 User-Agent 문자열(디바이스 구분용). 알림 전송 및 토큰 갱신 목적에만 사용하며 본인 외에는 공개되지 않습니다.
  • 사용자 작성 콘텐츠: 리뷰(별점·메모), 방문 기록(날짜·메뉴·메모·사진), 댓글, 가게 메뉴·가격 정보.
  • 활동 데이터: 좋아요, 댓글, 팔로우, 페이지 조회수.
  • 입맛 데이터: 입맛 진단 설문 응답 및 리뷰 활동에서 계산된 6축 입맛 벡터. 추천 매칭에 사용.

공개 범위

서비스는 커뮤니티 기반이므로 다음 정보는 다른 이용자에게 공개됩니다.

  • 사용자명, 닉네임, 자기소개, 프로필 사진
  • 입맛 진단 결과 코드(예: NCVR) 및 6축 입맛 벡터
  • 작성한 리뷰·방문 기록(메뉴·메모·사진 포함)·댓글·등록한 가게의 메뉴·가격 정보
  • 좋아요, 팔로잉·팔로워 관계, 가게 페이지 조회수

다음 정보는 본인 외에 공개되지 않으며 RLS(Row-Level Security)로 기술적으로 분리됩니다.

  • 이메일 주소
  • 위치 인증에 사용된 GPS 좌표
  • 푸시 알림 토큰, User-Agent 등 디바이스 식별 정보
  • 알림 수신 기록, API 호출 카운트, 신고 내역
  • 내맛집 폴더 구성

2. 이용 목적

  • 회원 인증 및 계정 관리
  • 맛집 위치 인증 (등록 시 실제 방문 여부 확인)
  • 비슷한 입맛 이용자 기반 맛집 추천
  • 좋아요·댓글·팔로우 발생 시 푸시 알림 발송
  • AI 소개글 생성 (가게별 정보 자동 정리)
  • 서비스 운영·개선 및 부정 이용 방지

3. 제3자 제공 및 처리 위탁

서비스는 다음 사업자에 개인정보 처리를 위탁합니다.

  • Supabase Inc. — 데이터베이스·인증·파일 저장. 모든 수집 데이터의 저장소.
  • Google LLC — Google OAuth 로그인.
  • Kakao Corp. — Kakao OAuth 로그인. 이메일·프로필 제공 동의 시 해당 정보가 서비스에 전달됨.
  • Naver Cloud Platform — 지도 표시, 가게 검색, 블로그 검색(Naver Search API), AI 소개글(Clova Studio).
  • Expo (EXP Inc.) / Google Firebase Cloud Messaging — 모바일 푸시 알림 전송.
  • Render Services, Inc. — 웹 서비스 호스팅.
  • GitHub, Inc. — 본 개인정보처리방침 정적 페이지 호스팅(GitHub Pages).

서비스는 위 목적 외 제3자에게 개인정보를 판매하거나 광고용으로 제공하지 않습니다.

4. 보관 기간

  • 회원 탈퇴 시까지 보관합니다.
  • 탈퇴 시 회원 식별 정보·리뷰·활동 기록은 즉시 삭제됩니다. 단, 다른 이용자가 작성한 콘텐츠 안에서 인용되거나 통계로 집계된 비식별 데이터는 남을 수 있습니다.
  • 관련 법령에 따라 일정 기간 보관이 필요한 경우 해당 기간 동안만 제한된 목적으로 보관 후 파기합니다.

5. 이용자의 권리

이용자는 다음 권리를 행사할 수 있습니다.

  • 개인정보 열람 — 프로필·작성 콘텐츠 페이지에서 직접 확인
  • 정정·수정 — 프로필 편집, 리뷰 수정 기능
  • 삭제·처리정지 — 리뷰 삭제, 회원 탈퇴
  • 알림 수신 거부 — 푸시 알림 설정에서 해제

위 권리는 앱·웹 화면에서 직접 행사할 수 있으며, 행사가 어렵거나 추가 요청 사항이 있는 경우 아래 연락처로 문의해 주세요.

6. 안전성 확보 조치

  • 전송 구간 HTTPS 암호화
  • 비밀번호는 OAuth에 위임(서비스가 직접 저장하지 않음)
  • 데이터베이스 접근 권한 최소화 및 Row-Level Security 적용
  • 관리자 작업 감사 로그 보관

7. 만 14세 미만 아동

서비스는 만 14세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다. OAuth 제공자(Google·Kakao)의 연령 정책을 따릅니다.

8. 변경 고지

본 방침이 변경되는 경우 변경 내용과 시행일을 본 페이지에 게시하여 최소 7일 전에 안내합니다. 중요한 변경 사항은 앱 내 공지 또는 푸시 알림으로 별도 고지합니다.
